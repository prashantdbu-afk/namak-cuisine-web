# Namak Cuisine Website

Build and maintain an original, accessible, fast website for Namak Indian Restaurant & Bar. Centralize verified business facts in `src/config/site.ts`; treat all other claims and media as owner-review items. Use Next.js 16 App Router, strict TypeScript, pnpm, Tailwind CSS 4, provider-neutral integrations, semantic HTML, and minimal client JavaScript. GitHub is the source of truth; quality gates are lint, typecheck, test, and build. Never commit secrets, fabricate reviews or credentials, hotlink media, or add Jenkins.
