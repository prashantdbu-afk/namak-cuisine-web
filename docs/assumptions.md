# Safe assumptions and owner review

- `OWNER_REVIEW_REQUIRED`: All marketing copy and draft menu names are original placeholders for owner approval; no prices or dietary claims are shown.
- `OWNER_REVIEW_REQUIRED`: CSS art stands in for food, bar, interior, exterior, and team photography. It must be replaced only with licensed or owner-provided media.
- `OWNER_REVIEW_REQUIRED`: Bar content is enabled as a general atmosphere page without named drinks, ingredients, or claims.
- `OWNER_REVIEW_REQUIRED`: Private dining and catering availability is framed as an inquiry, not guaranteed service or capacity.
- `OWNER_REVIEW_REQUIRED`: Parking, transit, physical accessibility details, chef history, coordinates, awards, press, reviews, and certifications are omitted.
- Reservation mode is `call`; order action is hidden because no URL is verified.
- Forms are unavailable because no provider is configured. The UI directs guests to call instead and never pretends a message was sent.
- Regular published hours are used with an empty special-hours override list; owners must add holiday exceptions.
